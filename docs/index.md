# Low Pass Gate

![Faceplate](./assets/images/lpg-dark.png#only-dark){: width="120", align=right}
![Faceplate](./assets/images/lpg-light.png#only-light){: width="120", align=right}

Buchla-style VCA and Sallen-Key VCF with vactrols.

* Module size: 6HP (30mm)
* Power: 12mA (+12V); 12mA (-12V)

!!! repository "Project Source"

    The project files, including schematic and layout, are available on [github](https://github.com/xdylanm/low-pass-gate).

## Features

* Pluck input with manual controls for length and level
* CV input with manual controls for level and offset
* Resonance
